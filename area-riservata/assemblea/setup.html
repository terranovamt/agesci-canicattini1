Salva su GitHub

Per scrivere dati.js serve un token GitHub. Si crea una volta e resta solo su questo dispositivo.

  1. Apri github.com → Fine-grained token.
  2. Repository access → Only select repositories → .
  3. Permissions → Contents → Read and write.
  4. Generate token, copialo e incollalo qui.
